# Сайт-резюме Максима Чечёткина

Статическая страница без сборки, сторонних библиотек, аналитики и внешних шрифтов.

## Локальный запуск

Из этой папки:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765. Также можно открыть index.html напрямую.

## Изменения

- `content.js` — имя, контакт, все внешние ссылки и карточки проектов. Пустые ссылки скрываются. Демо добавлять только после проверки.
- `index.html` — структура, описание, опыт, стек.
- `styles.css` — адаптивная вёрстка и темы. По умолчанию тема системы; переключатель в подвале.
- `script.js` — безопасное создание карточек, подключение ссылок, переключение темы.

## Дизайн и движение

Редизайн в духе презентационных страниц Apple: крупная типографика, полупрозрачная закреплённая навигация, светлая и тёмная фиолетовые темы. На десктопе карточки проектов закрепляются и последовательно перекрывают друг друга. На телефонах и низких экранах используется обычная вертикальная раскладка. Появление текста управляется IntersectionObserver, без обработчика каждого события scroll. При prefers-reduced-motion движение и закрепление отключаются; для печати все блоки видны.

Фрагменты кода в content.js взяты из ранее проверенных файлов проектов; переносы строк адаптированы для карточек.

Заголовок Fullstack Developer циклически печатается и сменяется Backend Developer / Frontend Developer. При уменьшении движения отображается статично; в скрытой вкладке таймер приостанавливается. SQLAlchemy указан как ORM в разделе баз данных.
